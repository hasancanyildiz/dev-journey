# Görev Takip Uygulaması

Terminal tabanlı basit bir görev takip (to-do) uygulaması.

## Özellikler
- Görev ekleme
- Görevleri listeleme
- Görevi tamamlandı olarak işaretleme
- Görev silme
- Görevler JSON dosyasında kalıcı olarak saklanır

## Nasıl Çalıştırılır
python3 todo.py

## Kullanılan Teknolojiler
- Python 3
- json modülü (kalıcı veri saklama)
- match-case (menü kontrolü için if elif else yerine kullanılmıştır.)
