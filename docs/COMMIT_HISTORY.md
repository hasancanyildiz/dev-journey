# Commit Geçmişi Dönüşümü — Conventional Commits

Bu repodaki commit mesajları [Conventional Commits](https://www.conventionalcommits.org/) formatına uygun hale getirilmiştir. Aşağıda **değişen** mesajların eski/yeni karşılaştırması yer almaktadır.

| Eski Mesaj | Yeni Mesaj (Conventional) |
|---|---|
| ilk commit | chore: ilk commit, proje başlatıldı |
| kurulum raporu eklendi | docs: kurulum raporu eklendi |
| Update title to include 'Gün 2' in report | docs: Gün 2 rapor başlığı güncellendi |
| dosya adları düzeltildi, görseller eklendi | fix: dosya adları düzeltildi, görseller eklendi |
| Terminlakomutları cheet sheeteeklendi | docs: terminal komutları için kısa başvuru rehberi eklendi |
| linux dizin yapısı notları eklendi | docs: linux dizin yapısı notları eklendi |
| haftalık rapor 1 eklendi | docs: 1. hafta raporu eklendi |
| hafta 2 car-per ekran goruntuleri eklendi | docs: 2. hafta car-per ekran görüntüleri eklendi |
| hafta 2 raporu eklendi | docs: 2. hafta raporu eklendi |
| Stack pratiği yapıldı . | feat: Stack uygulaması eklendi |
| Queue pratiği yapıldı. | feat: Queue uygulaması eklendi |
| hafta 4 raporu eklendi | docs: 4. hafta raporu eklendi |

Zaten conventional format'ta olan commit'ler (örn. `feat:`, `docs:` ile başlayanlar) ve merge commit'leri değiştirilmeden korunmuştur.
